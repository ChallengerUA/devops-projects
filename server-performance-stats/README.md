# Server Performance Stats

A simple CLI tool written in Bash to analyze basic server performance statistics from the command line.

## Description

This script collects and displays key performance metrics of a Linux server in a clean and readable format. It is part of my DevOps challenge from [roadmap.sh](https://roadmap.sh).

## Usage

```bash
bash server-stats.sh
```

## What it does

- Shows CPU usage
- Shows memory usage (free vs used)
- Shows disk usage (free vs used)
- Shows top 5 processes by CPU usage
- Shows top 5 processes by memory usage
- Shows OS version, uptime and load average
- Shows currently logged in users

## Requirements

- Linux/Unix based system
- Bash
